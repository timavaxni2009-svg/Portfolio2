# ААРЕНДА АВТО

Одностраничный сайт для вымышленного сервиса по прокату автомобилей в Волгограде. Проект демонстрирует навыки семантической и адаптивной вёрстки, а также работу с современными CSS-инструментами.

## 🎯 Ключевые особенности

*   **Семантическая вёрстка**: Использование HTML5-тегов (`header`, `main`, `nav`, `section`, `article`, `form`) для создания логичной и доступной структуры документа.
*   **Адаптивный дизайн**: Сайт корректно отображается на экранах от 360px до 4K. Реализованы четыре контрольные точки: 1024px, 750px.
*   **CSS-архитектура**: Проект использует дизайн-токены (CSS-переменные) для цветов, радиусов и анимаций, что обеспечивает единообразие и лёгкость поддержки.
*   **Интерактивные элементы**: Форма подбора автомобиля с полями выбора даты, времени и места.
*   **Оптимизация**: Изображения используют атрибут `loading="lazy"` для ленивой загрузки.
